**Grammar:** about 1.3 s per repo. The camera tilts down, a patch cable is the carrier, the counter is the progress bar, and every module has a working micro-demo. The look is warm pastel modules on a pink floor. Text is name + one-liner, with mono labels for `/add <repo>` and `✓ patched`.

**Their weak points, where we beat them:**
1. No voice: the story is only text you have to read at 1.3 s per repo.
2. The demos are tiny screens inside modules. At phone size you can't see what changed.
3. There's no single thing that gets better: 18 unrelated demos.
4. There's no proof. Stars and pages are never shown, and the end card holds 3.6 s, beyond the 1.4 s end-card limit.
5. 4:5 rather than 9:16.

**DO NOT COPY:** the modular-synth rack, the pastel module panels, patch cables, the "18 skills. One patch." card, their wording, their layout.

**Our idea (it only works with this list):** ONE BALL, 18 UPGRADES. The classic first animation exercise, a bouncing ball, starts as linear AI slop. Each repo visibly upgrades the same ball, and the layers add up. The voice (Liam, Hinglish) names each repo as it acts. Each repo's real GitHub page and its live star count (GitHub API, 2026-11-20) sit beside its upgrade. The payoff is the finished ball with all 18 layers, then a before/after split.
