=== 2. TECHNICAL (for engineers) ===
BRIDGE.EXE: a linear-elastic 2D truss lab in the browser (React Three Fiber). Direct-stiffness solver in TypeScript (dense Gaussian elimination, zero-pivot = mechanism, equilibrium + residual on every run), cross-checked against an independent numpy solver and PyNite 3.2.1 (worst relative difference 1.99e-11) and the OpenSeesPy truss example. Beam mode: Euler–Bernoulli FE reproducing PL³/48EI and 5wL⁴/384EI.
Reel run R001: 56 m Pratt, 8 panels, deck 20 kN/m + 300 kN truck per plane + self-weight → 127.0 mm (L/441), max |N| 1908 kN, reactions 779 + 779 kN. Deeper truss (h 8 m): 85.7 mm, +8 % steel, one vertical hits the Euler-based proxy (1.02).
Exports: CSV report with run ID + input hash, GLB, and a conceptual IFC4X3 (IfcBridge + 58 IfcMember with result Psets) via IfcOpenShell. Utilisation is an educational proxy (CHS t = D/20, Euler) — not code compliance. Loads are illustrative, not IRC/IS load models. No Autodesk MCP was used. Arcade collapse = Rapier game effect.
