=== DM REPLY (for "SAFE") ===
Yeh rahi developer safety checklist 🛡
1. Recruiter verify karo: company ki official site / LinkedIn page se contact cross-check, personal email ya chat-app-only "CEO" = red flag.
2. Interview assignment / unknown repo kabhi work laptop pe nahi: ek disposable VM ya cloud sandbox use karo, bina company login ke.
3. Run karne se pehle padho: install scripts, postinstall hooks, binaries, obfuscated code.
4. Dev tools sirf official source se: search ad ke link se nahi, official docs/website se install karo.
5. Work credentials isolate: SSH keys, tokens, wallet / prod access personal ya test machine pe kabhi nahi.
6. Kuch bhi ajeeb lage: turant apni security team ko report karo.
Source for the story: Binance, "Initial Findings and Response Update", 3 Nov 2026.
