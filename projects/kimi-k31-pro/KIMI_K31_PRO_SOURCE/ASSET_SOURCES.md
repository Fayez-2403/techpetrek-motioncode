## V3 showcase
- Every shot (sky flight, board flight, duel, racing, zombie survival, rooftop parkour, architecture simulation, future city, town,
  Blender-style viewport, 3D website, 3D scroll site, interactive art site, interactive storytelling, interactive art) is procedural
  Three.js / DOM built for this video (src/v3/). Structure, pacing and scene types follow the official "Meet Kimi K3.1 Pro" film as the
  user asked; no shot, frame, character design, footage or music of that film was copied. No real brands, car makes, game titles,
  Blender branding, real people or landmarks. All site names are fictional `.example` domains; copy is fictional sample text.
- Each shot carries "ILLUSTRATIVE · BUILT IN CODE FOR THIS VIDEO · NOT KIMI OUTPUT"; the intro and finale repeat it.

## Not used (deliberately)
- **No Moonshot / Kimi logos or screenshots.** "KIMI" and "K3.1 PRO" are set in our own type (Unbounded); no official marks,
  so nothing can be mistaken for an official production. No Claude/OpenAI/Google logos either (model names as plain text).
- **No footage from the reference video** (https://youtu.be/DIyHTpfWctU, the official "Meet Kimi K3.1 Pro" film). It was downloaded
  only to study pacing and craft; frames stayed in the session scratchpad and were never copied into this project.
- **No official Moonshot demo videos.** The article embeds K3.1 Pro example videos (walking simulator, turbofan, Godot game, etc.).
  Using them would need Moonshot's permission (third-party material); without it, every demo here is an original reconstruction.
- No stock images, stock music or sample packs: all 3D is procedural Three.js, all music and sound effects are synthesized in
  audio-src/score.py.
