# Dialogue

Liam reads six short Hinglish directions. The opening asks viewers to imagine their own night drive. The final line invites them to try the starter prompt in GPT-6.2 Astra. The actual words, in both scripts, are in [voScript.json](../src/config/voScript.json). The [Roman Hinglish subtitles](../post/nightshift.srt) use provider character alignment.
