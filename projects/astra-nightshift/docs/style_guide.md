# Nightshift art direction

The frame is a portrait game trailer. Blue-black street canyons, amber lamps, wet white metal and thin red taillights define the street. Chrome on the courier’s visor carries that palette into the character selector. Paper-white Archivo carries editorial titles. JetBrains Mono identifies an instruction or camera, and the current spoken word turns amber in the captions. The original square Techpetrek mark occupies 10% of frame width, 62 design pixels from the right and 150 from the bottom.
