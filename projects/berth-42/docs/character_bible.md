# Character bible: Berth 42 (design sheet v1, 2026-11-27)

All five are drawn in code. Each is one file in `cast/`, a jointed cut-out rig (`figure(expr, angles, look, hands)`, with two-bone IK for the hands) plus `head(expr)`.
The sheet is `out/design/DESIGN_SHEET_berth42_v1.png`. Every character has the same salmon skin (`#f08470`), one shade tone and one light tone, and a hard diagonal shade (light from the upper left).
