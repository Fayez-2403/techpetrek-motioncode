# Mumbai After Rain

GPT-6.2 Astra built this playable Mumbai monsoon night drive in Three.js: the city, the Monsoon GT coupe, kaali-peeli
taxis, rickshaws, the red bus, the "आख़िरी लोकल" cinema poster, the driving physics and the replay cameras. The 56 s
Techpetrek reel is captured frame by frame from the game itself. **Everything for this reel is in this folder.**

## What's where
| Folder / file | What |
|---|---|
| `mumbai-game/play-mumbai.html` | the playable offline game (generated by the build; don't edit it) |
| `mumbai-game/src/` | `city.js` (streets, signs, poster) · `vehicles.js` · `route.js` (road, traffic) · `game.js` (physics, cameras) · `hud.js` (captions, speed, minimap, logo) · `main.js` (menu, capture) · `engine-audio.js` · `captions.json` (generated from the voice) |
| `mumbai-game/scripts/` | `build.mjs` (one-file game) · `capture.mjs` (tests, stills, recording) · `contact_sheet.py` |
| `src/config/mumbai-drive.json` | **the voice script**: lines, timing, caption phrases, Liam voice settings (`"tts"`) |
| `scripts/cutting_dialogue.py` | voice generator: ElevenLabs takes (cached in `audio/takes/`) → `audio/out/mumbai-drive/dialogue.wav` + captions + srt |
| `scripts/v3_mix.py` | music + engine + voice mix → `public/audio/mumbai-drive.m4a` (−14 LUFS) |
| `public/` | the mix, the Techpe Trek logo, the Archivo font (embedded into the game by the build) |
| `index.html` | HyperFrames composition of the finished preview |
| `docs/mumbai-claude-handoff.md` | the full creative and technical handoff (with the v2 notes) · `docs/mumbai-drive.md` |

## Rebuild (from this folder)
```powershell
npm run voice      # new script lines -> voice + captions (only changed lines call ElevenLabs)
npm run mix        # score + engine + voice, -14 LUFS
npm run build      # embeds the mix + captions into play-mumbai.html
npm test           # controls, steering, braking, paint, menu, voiced replay
npm run stills     # 12 review frames at 1080x1920
npm run preview    # the sharp 1080x1920 reel -> out/mumbai-drive-preview/mumbai-drive-preview.mp4
```
QA: `python ../../analysis/reel_qa.py out/mumbai-drive-preview/<file>.mp4 --frames 1680 --max-dur 59.9`
