=== DM 2: the setup ===
Setup (Claude Code / any coding agent):

Agent skills (1-5, 7, 12, 13, 17) go in with one line, e.g.
npx skills add NiazMorshed2007/reanimate -g
(same pattern for the others; check each README)

Libraries:
pip install manim librosa whisperx
npm i three.quarks @react-three/postprocessing tweakpane
FFmpeg: winget install ffmpeg (Win) / brew install ffmpeg (Mac)

Start with reanimate: give it a URL, screen recording, mp4 or gif of the motion you like, and it rebuilds it frame by frame.
